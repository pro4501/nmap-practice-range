Cheat sheet

The flags this range understands, and what nmap's answers mean.

Port states

StateWhat nmap saw
openA service answered: SYN/ACK for TCP, or a UDP reply.
closedThe host answered RST (TCP) or ICMP port unreachable (UDP). Reachable, but nothing listens.
filteredNo reply, or an ICMP "administratively prohibited". A firewall is in the way.
unfilteredACK scan only. The probe got through, but open vs closed is unknown.
open|filteredUDP, FIN, NULL and Xmas scans. Silence could mean open or dropped.

Host discovery

-snPing sweep only, no port scan
-PnSkip discovery and treat every target as up
-PE -PS443 -PA80Choose discovery probes: ICMP echo, TCP SYN, TCP ACK
-nNo reverse DNS lookups

Scan types

-sSSYN (half-open). Default as root
-sTFull TCP connect. Default without root
-sUUDP. Slow; pair with --top-ports
-sAACK. Maps firewall rules
-sF -sN -sXFIN, NULL, Xmas. RST means closed

Ports

-p 22,80,443A list
-p 1-1024A range
-p-All 65,535 ports
-p U:53,T:22Per protocol (with -sU -sS)
-FTop 100 ports
--top-ports 20Top N ports (default is 1,000)

Detection and output

-sVService and version detection
-sCDefault NSE scripts (-sCV combines both)
-OOS detection (needs root)
-A-sV -sC -O --traceroute
-T0…-T5Timing: paranoid, sneaky, polite, normal, aggressive, insane
--reasonShow why each port got its state, with TTL
--openOnly show open (or possibly open) ports
-vVerbose progress
-oN f -oG f -oA baseSave normal, grepable, or all formats (read with cat)

Exam tips

  • sudo changes everything: -sS, -sU and -O need root, and discovery switches from TCP connects to ICMP plus raw TCP probes.
  • If a sweep misses a host you expect, scan it with -Pn.
  • Default scans cover 1,000 ports. Services on high ports only show with -p-.
  • TTL hints at the OS: about 64 for Linux, 128 for Windows, 255 for printers and network gear, minus one per router.
  • Windows answers FIN, NULL and Xmas probes with RST, so those scans show its open ports as closed.
